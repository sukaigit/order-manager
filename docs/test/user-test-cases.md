# 订单管理系统 — 用户测试案例（Playwright）

基于 `openspec/specs/` 逐条编写。每个 Scenario 对应一个用户测试案例，描述用户操作步骤和预期结果。

---

## 1. 首页 — Dashboard

### UT-DASH-001: 访问首页
- **操作:** 用户在浏览器打开首页 `/dashboard`
- **预期:** 页面显示 4 张统计卡片（累计订单数/累计订单金额/累计已结清订单数/累计已结清订单金额）
- **状态:** ✅

### UT-DASH-002: 查看近期订单
- **操作:** 在首页滚动到近期订单区域
- **预期:** 显示最近订单表格，含订单编号/类型/合作方/金额/状态/时间列
- **状态:** ✅

### UT-DASH-003: 查看订单分布
- **操作:** 在首页查看订单分布卡片
- **预期:** 显示中间业务/数据开发/应用开发的单数和金额
- **状态:** ✅

### UT-DASH-004: 查看合作方排名
- **操作:** 在首页查看合作方排名卡片
- **预期:** 显示多个合作方，按金额降序排列
- **状态:** ✅

## 2. 订单管理 — Order

### UT-ORDER-001: 查看订单列表
- **操作:** 用户点击侧边栏「订单管理」
- **预期:** 页面加载订单列表，显示订单编号/类型/合作方/金额/状态/时间/操作列，有分页控件
- **状态:** ✅

### UT-ORDER-002: 筛选订单
- **操作:** 
  1. 在筛选栏选择订单类型
  2. 点击「查询」按钮
- **预期:** 列表只显示匹配的订单
- **状态:** ✅

### UT-ORDER-003: 重置筛选
- **操作:** 筛选后点击「重置」按钮
- **预期:** 筛选条件清空，列表恢复全部数据
- **状态:** ✅

### UT-ORDER-004: 翻页
- **操作:** 
  1. 点击「下一页」按钮
  2. 点击页码「1」
- **预期:** 页面切换，数据更新
- **状态:** ✅

### UT-ORDER-005: 新增订单
- **操作:**
  1. 点击「新增订单」按钮
  2. 弹出表单显示：订单名称/订单类型/合作方/金额
  3. 填写必填字段
  4. 点击「保存」
- **预期:** 保存成功，新订单出现在列表中
- **状态:** ✅

### UT-ORDER-006: 编辑订单（仅待审核）
- **操作:**
  1. 找到一条待审核订单
  2. 点击「编辑」按钮
  3. 弹出编辑表单
  4. 修改字段
  5. 点击「保存」
- **预期:** 保存成功，字段更新
- **状态:** ✅

### UT-ORDER-007: 删除订单（仅待审核）
- **操作:**
  1. 找到一条待审核订单
  2. 点击「删除」按钮
  3. 弹出确认框
  4. 点击「取消」
- **预期:** 确认框出现，取消后不删除
- **状态:** ✅

### UT-ORDER-008: 导出订单
- **操作:** 点击「导出」按钮
- **预期:** 浏览器下载 .xls 文件
- **状态:** ✅

- **预期:** 页面加载合作方列表，显示合作方编号/名称/联系人/联系电话/备注/操作列

### UT-PARTNER-002: 新增合作方

  2. 弹出表单显示：合作方名称/联系人/联系电话
  3. 填写必填字段

- **预期:** 保存成功，自动生成合作方编号 PARTNER-{NNN}，列表更新
- **状态:** ✅

### UT-PARTNER-003: 编辑合作方
- **操作:**
  1. 点击任意合作方的「编辑」按钮
  2. 弹出编辑表单
  3. 修改联系人

- **预期:** 保存成功，列表字段更新
- **状态:** ✅

### UT-PARTNER-004: 删除无订单合作方
- **操作:**

  2. 点击「删除」按钮
  3. 弹出确认框：「确定要删除合作方「xxx」吗？」
  4. 点击「取消」
- **预期:** 确认框出现，取消后不删除
- **状态:** ✅

### UT-PARTNER-005: 筛选合作方
- **操作:**

- **预期:** 列表只显示匹配数据

- **操作:** 点击「重置」按钮
- **预期:** 搜索条件清空，列表恢复全部
- **状态:** ✅

### UT-PARTNER-007: 导出合作方
- **操作:** 点击「导出」按钮
