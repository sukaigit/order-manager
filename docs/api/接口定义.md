# 订单管理系统 — API 接口定义

Base URL: `/api`

---

## 1. 订单管理 `/api/orders`

### 1.1 分页查询订单
`GET /api/orders`
- Query 参数: `page`(默认1), `pageSize`(默认5), `code`, `type`, `partner`, `status`
- 响应:
```json
{ "code": 200, "data": { "list": [...], "total": 10 } }
```

### 1.2 新增订单
`POST /api/orders`
- 请求体: `{ "name":"", "type":"", "partner":"", "amount":0, "remark":"" }`
- 自动生成: `code`(ORD-{日期}-{序号}), `date`, `status`(待审核)

### 1.3 编辑订单
`PUT /api/orders/{id}`
- 请求体: `{ "name":"", "type":"", "partner":"", "amount":0, "remark":"" }`
- 规则: 仅 status=待审核 可编辑

### 1.4 删除订单
`DELETE /api/orders/{id}`
- 规则: 仅 status=待审核 可删除

### 1.5 导出订单
`GET /api/orders/export?code=&type=&partner=&status=`
- 响应: Excel 文件流

## 2. 合作方管理 `/api/partners`

### 2.1 分页查询合作方
`GET /api/partners?page=&pageSize=&code=&name=&contact=`

### 2.2 新增合作方
`POST /api/partners`
- 请求体: `{ "name":"", "contact":"", "phone":"", "remark":"" }`
- 自动生成: `code`(PARTNER-{NNN})

### 2.3 编辑合作方
`PUT /api/partners/{id}`

### 2.4 删除合作方
`DELETE /api/partners/{id}`
- 规则: 有关联订单则返回 400

### 2.5 导出合作方
`GET /api/partners/export`

### 2.6 合作方列表（下拉用）
`GET /api/partners/list`
- 响应: `[{ "code":"PARTNER-001", "name":"合作方A" }, ...]`

## 5. 用户管理 `/api/users`

### 5.1 分页查询用户
`GET /api/users?page=&pageSize=&code=&name=&role=&dept=&org=&status=`

### 5.2 新增用户
`POST /api/users`
- 请求体: `{ "name":"", "role":"", "dept":"", "org":"", "active":true }`
- 密码默认 `Uu888888!`, first_login=true

### 5.3 编辑用户
`PUT /api/users/{id}`

### 5.4 删除用户
`DELETE /api/users/{id}`

### 5.5 锁定/解锁用户
`PUT /api/users/{id}/lock?locked=true|false`

### 5.6 重置密码
`PUT /api/users/{id}/reset-pwd`
- 密码重置为 `Uu888888!`, first_login=true

### 5.7 修改密码
`PUT /api/users/{id}/change-pwd`
- 请求体: `{ "oldPwd":"", "newPwd":"" }`

## 12. 认证 `/api/auth`

### 12.1 登录
`POST /api/auth/login`
- 请求体: `{ "name":"", "password":"", "captcha":"" }`
- 响应: `{ "token":"...", "user":{...}, "firstLogin":true|false }`

### 12.2 验证码
`GET /api/auth/captcha`
- 响应: 图片 base64 + captchaId

### 12.3 退出
`POST /api/auth/logout`
