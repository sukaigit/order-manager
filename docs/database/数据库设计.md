# 订单管理系统 — 数据库设计

## 数据库
```sql
CREATE DATABASE IF NOT EXISTS order_manager DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 应用用户
```sql
CREATE USER IF NOT EXISTS 'order_mgr'@'localhost' IDENTIFIED BY 'Uu888888!';
GRANT SELECT, INSERT, UPDATE, DELETE ON order_manager.* TO 'order_mgr'@'localhost';
FLUSH PRIVILEGES;
```

## 表结构

### 系统管理表

#### tb_user 用户表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(30) | UNIQUE NOT NULL | 用户编号 |
| name | VARCHAR(50) | NOT NULL | 用户名 |
| password | VARCHAR(200) | NOT NULL | 密码(bcrypt) |
| role | VARCHAR(20) | NOT NULL | 角色 |
| dept | VARCHAR(50) | DEFAULT '' | 部门 |
| org | VARCHAR(20) | DEFAULT '' | 机构编码 |
| active | TINYINT(1) | DEFAULT 1 | 启用/禁用 |
| locked | TINYINT(1) | DEFAULT 0 | 锁定 |
| first_login | TINYINT(1) | DEFAULT 1 | 首次登录标记 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_department 部门表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(20) | UNIQUE NOT NULL | 部门编号 |
| name | VARCHAR(50) | NOT NULL | 部门名称 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_organization 机构表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(20) | UNIQUE NOT NULL | 机构编号 |
| label | VARCHAR(100) | NOT NULL | 机构名称 |
| sname | VARCHAR(50) | NOT NULL | 机构简称 |
| level | VARCHAR(10) | NOT NULL | 层级: hq/branch1/branch2/sub1/sub2 |
| parent | VARCHAR(20) | DEFAULT '' | 父级编码 |
| contact | VARCHAR(50) | DEFAULT '' | 联系人 |
| phone | VARCHAR(20) | DEFAULT '' | 联系电话 |
| region | VARCHAR(100) | NOT NULL | 所在地区 |
| address | VARCHAR(200) | NOT NULL | 详细地址 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_role 角色表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(30) | UNIQUE NOT NULL | 角色编号 |
| name | VARCHAR(50) | NOT NULL | 角色名称 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_role_function 角色权限关联表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| role_id | BIGINT | FK → tb_role.id | 角色ID |
| func_code | VARCHAR(50) | NOT NULL | 功能编码 |

#### tb_menu 菜单表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(30) | UNIQUE NOT NULL | 菜单编号 |
| label | VARCHAR(50) | NOT NULL | 菜单名称 |
| route | VARCHAR(50) | DEFAULT '' | 路由路径 |
| type | VARCHAR(10) | NOT NULL | level1/level2 |
| parent | VARCHAR(30) | DEFAULT '' | 父级菜单编码 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_function 功能权限表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(50) | UNIQUE NOT NULL | 功能编码 |
| name | VARCHAR(50) | NOT NULL | 功能名称 |
| menu | VARCHAR(50) | NOT NULL | 所属菜单 |
| perm | VARCHAR(50) | UNIQUE NOT NULL | 权限标识 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |

#### tb_operation_log 操作日志表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| user | VARCHAR(50) | NOT NULL | 操作人 |
| action | VARCHAR(50) | NOT NULL | 操作类型 |
| target | VARCHAR(100) | NOT NULL | 操作目标 |
| ip | VARCHAR(50) | DEFAULT '' | IP地址 |
| time | DATETIME | NOT NULL | 操作时间 |

### 业务表

#### tb_partner 合作方表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(20) | UNIQUE NOT NULL | 合作方编号 PARTNER-{NNN} |
| name | VARCHAR(100) | UNIQUE NOT NULL | 合作方名称 |
| contact | VARCHAR(50) | NOT NULL | 联系人 |
| phone | VARCHAR(11) | NOT NULL | 联系电话 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |
| update_time | DATETIME | NOT NULL | 更新时间 |

#### tb_order 订单表
| 字段 | 类型 | 约束 | 说明 |
|:----|:----|:----|:-----|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| code | VARCHAR(30) | UNIQUE NOT NULL | 订单编号 |
| name | VARCHAR(200) | NOT NULL | 订单名称 |
| type | VARCHAR(20) | NOT NULL | 订单类型 |
| partner_id | BIGINT | FK → tb_partner.id | 合作方 |
| amount | DECIMAL(12,2) | NOT NULL | 订单金额 |
| status | VARCHAR(10) | NOT NULL | 待审核/已下单/已结清 |
| order_time | DATETIME | NOT NULL | 订单时间 |
| remark | VARCHAR(500) | DEFAULT '' | 备注 |
| create_time | DATETIME | NOT NULL | 创建时间 |
| update_time | DATETIME | NOT NULL | 更新时间 |

## 索引
- tb_order: idx_order_code, idx_order_type, idx_order_status, idx_order_partner, idx_order_time
- tb_partner: idx_partner_code, idx_partner_name
- 系统表: 按 code/name 建唯一索引
